# Sécurité

Pour signaler une faille, utilisez le signalement privé de GitHub :
onglet « Security », puis « Report a vulnerability ». Merci de ne pas ouvrir de
ticket public pour une faille.

Le dépôt ne contient aucun secret. Les clés (Zotero, OpenAlex) et le mot de passe
Neo4j se lisent dans des variables d'environnement (voir `.env.example`).
